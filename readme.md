# Meus dados

Página pessoal em HTML para reunir informações úteis em consultas, no trabalho
e em situações de emergência.

## Conteúdo

- Dados pessoais e profissionais de saúde.
- Diagnósticos e condições clínicas.
- Características e necessidades de apoio.
- Orientações para atendimento em saúde ou situações de crise.
- Contatos de emergência.

## Como visualizar

Abra o arquivo `index.html` diretamente em um navegador. Não é necessário
instalar dependências nem iniciar um servidor.

## Arquivos

- `index.html`: conteúdo, estrutura, estilos e comportamento da página.
- `max-saldanha-dark.png`: imagem de perfil usada no cabeçalho.

Mantenha os dois arquivos na mesma pasta para que a imagem seja carregada.

## Privacidade

O documento contém informações pessoais e de saúde, além de contatos. Revise o
conteúdo e os dados de contato antes de compartilhar ou publicar os arquivos.
